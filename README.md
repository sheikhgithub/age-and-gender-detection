
# 🧠 Age and Gender Detection Using Python

This project is a simple and effective implementation of **real-time age and gender detection** using Python and computer vision. The application uses a webcam to capture a person's face and predicts their **age group** and **gender** using pre-trained deep learning models.

## 🚀 Features

- 📷 Real-time webcam feed integration
- 👤 Face detection using OpenCV
- 🎯 Age group classification (e.g., 0-2, 4-6, 8-12, 15-20, etc.)
- 🧑‍🦰 Gender prediction (Male / Female)
- ✅ Lightweight and easy to run locally

## 🛠️ Technologies Used

- Python
- OpenCV
- Pre-trained Caffe models (for age and gender)
- NumPy
- dnn module from OpenCV
